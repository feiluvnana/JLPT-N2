## 問題1 課題理解

| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 4 | 担当者の「自動音声での受付か、公式Webサイトからのご申請をお願いしております」を受け、男の人が「Webサイトから申し込むのが確実で早そうですね」と述べている。1の窓口・3の配達員への電話はどちらも案内されていない。 |
| 2番 | 1 | 男の人の「何よりも先に訪問先の担当者様に連絡を入れて、遅れる旨をお詫びして到着時間を再調整してもらわないと」から1。2は「次の列車に乗るしかない」だけで手配の話はなく、3・4は女の人が「部長と、宿泊先のホテルには私から連絡しておきましょうか」と引き受けている。 |
| 3番 | 1 | 女の人の「スマホにアプリをダウンロードして現在地を指定すれば、一番近くにいるタクシーが迎えに来てくれるわ」を受け、男の人が「さっそくスマホでそのアプリを入れてみるよ」と述べている。3・4はどちらも女の人が挙げたが選ばれていない。 |
| 4番 | 2 | 担当者の「まず本人確認の書類をメールでお送りください」と、男の人の「では、今日中に送ります」から2。1の来店は「ご来店いただく日を決めましょう」と後回し、3の内見は「先日内見させていただいた」と済んでおり、4の保証人の署名は「契約書ができてからで結構です」と後になる。 |
| 5番 | 3 | 管理人の「事前に管理事務所へご連絡の上、一時的な車移動の手続きをお願いいたします」と、女の人の「さっそく事務所で手続きしておきます」から3。 |

## 問題2 ポイント理解

| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 1 | 教授の「本文中で引用している文献の表記方法が、指定のルールに従っていません」から1。2は「指定された文字数も満たしています」、4は「グラフやデータの使い方も適切です」と否定されており、3は話題に出ていない。 |
| 2番 | 2 | 男の人は昇降式デスクの効果を認めつつ、「慣れるまではずっと立って作業していると足や腰に疲労がたまるんだよね」と話している。 |
| 3番 | 3 | アナウンサーの「タイマーで途中で切るのではなく、設定温度を高めにして朝までつけっぱなしにしておくことが推奨されます」から3。1はタイマー設定を勧めているのではなく、2の扇風機は「併用して」であり、4は述べられていない。 |
| 4番 | 1 | 「運転手不足が深刻化しており、現在の運行便数を維持することが困難となっております」が変更の理由。夜間の減便と運行間隔の変更はその結果である。2・3は「道路工事に伴う迂回や、新しい駅へのルートの追加はございません」、4は「増便をお望みの声も多くいただいておりますが、当面は難しい状況です」と否定されている。 |

## 問題4 即時応答

| 番号 | 正解 | ポイント |
|---|---|---|
| 1番 | 1 | 依頼に対する承諾。「はい、喜んで引き受けさせていただきます」が適切。 |
| 2番 | 3 | 申し出に対する丁寧な辞退または確認。「あ、ありがとうございます。助かります」が適切。 |
| 3番 | 3 | 謙譲語の使い分け。「存じております」は「知っています」の謙譲語で、物事について用いる。1「存じ上げております」は人について用いる形、2「お聞きになっております」は自分の行為に尊敬語を使っており誤り。 |
| 4番 | 1 | 提案に対する意見。「あ、確かにそうですね。見直します」が適切。 |
| 5番 | 2 | 褒め言葉への返答。「気が利く」は配慮が行き届いていること。「いえいえ、滅相もありません」が適切。 |
| 6番 | 1 | 状況報告に対する返答。「そうですか。では日程を再調整しましょう」が適切。 |
| 7番 | 3 | 相手のお詫びに対する気遣い。「いえいえ、こちらこそ無理を言ってすみませんでした」が適切。1・2は「お役に立てず」という詫びと矛盾する。 |
| 8番 | 2 | 慣用句。「板につく」は職業や立場がしっくり馴染むこと。「おかげさまで、だいぶ慣れてきました」が適切。 |
| 9番 | 2 | 共感・同意。「ええ、マニュアルを見ながら少しずつ覚えていきます」が適切。 |
| 10番 | 1 | 慣用句。「願ってもない」は望んでも得られないほどありがたいという意味で、推薦を喜んで受ける「はい、願ってもないチャンスだと思っています」が適切。2・3は「願う」を字義通りに取った誤り。 |
| 11番 | 2 | 来客予定の確認。「承知いたしました。応接室を準備しておきます」が適切。 |
| 12番 | 3 | 感謝に対する返礼。「いいえ、皆さんのご協力のおかげです」が適切。 |
