| 番号 | 正解 | ポイント |

| 1番 | 1 | 依頼に対する承諾。「はい、喜んで引き受けさせていただきます」が適切。3「はい、お断りいたします」は文法的な矛盾。 |
| 2番 | 3 | 申し出に対する感謝と受け入れ。「あ、ありがとうございます。助かります」が適切。 |
| 3番 | 3 | 謙譲語の使い分け。「存じております」は「知っています」の謙譲語。 |
| 4番 | 1 | 指摘への同意と見直し。「あ、確かにそうですね。見直します」が適切。 |
| 5番 | 2 | 褒め言葉・気遣いに対する恐縮の表現。「いえいえ、とんでもございません」が適切。 |
| 6番 | 1 | 状況報告に対する次のアクションの提案。「そうですか。では日程を再調整しましょう」が適切。 |
| 7番 | 3 | お詫びに対する配慮。「いえいえ、こちらこそ無理を言ってすみませんでした」が適切。 |
| 8番 | 2 | 慣用句。「板につく」（慣れる）に対する受け答え。「おかげさまで、だいぶ慣れてきました」が適切。 |
