# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 女「ペンションにも、到着時間の変更を伝えてあるよね？」男「そうでした、すみません」→着く時間をペンションに伝える。バス会社への連絡は「もう知らせた」、集合時間は女が「連絡しておいたよ」で済み、持ち物は女が「みんなにメールで伝えておくね」。 |
| 2番 | 4 | 男「でなければ特急を利用するかですね」→女「乗り換えは間違えないかといつも心配で」→男「じゃあ、乗り換えはなしで」で特急に決まる。指定席は「もう禁煙車はいっぱいですね。喫煙車でもいいですか」に女「いや、タバコは困ります、私」と断られ、男「じゃあ、自由席になりますね」＝特急・自由席。1・2の新幹線は「北山で普通列車に乗り換えていただくことになりますね」で退けられている。 |
| 3番 | 2 | 男「少し目立つ色を入れたりするとか、してみてくれます？」女「あ、はい。そうですね」→箱のデザイン（色）を変更する。価格（3）と発売時期（4）は「企画書のままでいい」「今のように…書いていておいてくれれば十分」と変更なし、対象年齢（1）は話題に出ていない。 |
| 4番 | 3 | 1 ✗「記念品は袋に入れてくれた?」「まだ届いていないんですよ」「納品は3時だったね」→品物がまだ来ていない／2 ✗「花瓶の移動なんだけど、落とすといけないから記念品の準備の後で私と一緒にやりましょうか」→後回しになった／3 ○「記念品の到着を待ってる間、出席者の名前を書いた紙を椅子に貼ってくれない？」／4 ✗「明日の朝一番に卒業生代表のグエンさんと挨拶のリハーサルをお願いね」→明日。 |
| 5番 | 3 | 課長「パンフレットが入った封筒を各机に置いて準備は完了となります」→今日この後の作業。机といすは「準備が整い」、パソコンは「設置は当日行います」、来場者の案内は「当日は」。 |

## 問題2
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 1 ✗「来月、ビジネス雑誌にも取り上げられることになった」→これからのこと／2 ✗「特に有名な俳優さんを使って大きく宣伝をしたわけでもないのに」と否定／3 ○「歌手の吉田なつき…彼女がテレビ番組で最近のお気に入りだって紹介してくれたんです。それを見た人が購入してくれて広がっていったんです」→話題になったきっかけ／4 ✗「そのうちドラマとかでも使ってもらえたら」→希望。 |
| 2番 | 4 | 1 ✗「就職に有利になるところを実習先で探している人もいるけど、私はまだそこまでは考えてない」／2 ✗「職場でのコミュニケーションとかいろいろ心配」→不安であって期待ではない／3 ✗「会社員の生活ってどんなものか具体的にわかればいいんじゃない？」→男の意見／4 ○「今回の実習を通して自分が仕事でどう力を発揮できるか、そこを知りたいんだ」。 |
| 3番 | 2 | 先生「考察が自分の考えなのか、資料にある文を引用したのかが、曖昧なレポートが多く見られたので、次からはこの点に気をつけましょう」→引用と自分の考えを区別して書くこと。資料は「みなさん信頼できるものを使って書けていました」、文体は「話し言葉がまざることはなく、書けていました」、文字数は「今回はみなさん決められた文字数の中でうまくまとめられていました」と、いずれもできていた点。 |
| 4番 | 3 | 女「合わせるもので同じ着物とは思えないってくらい印象が変わるんだよ。私、そこから毎日着たいくらい大好きになっちゃった」＝夢中になったきっかけ。安さは高くない理由、古さは「そういうわけじゃない」、注目は「他の人の目は気にならないんだ」。 |
| 5番 | 2 | 1 ✗「無料のドリンクをつけようとかいろいろ意見は出たんですが」→採用されなかった案／2 ○「インパクトがある広告じゃなきゃ注文もしてもらえないと思いまして」「消滅の危機！売り上げが5位以内じゃなかったら、もう売りません！」と広告に入れた→売り上げを伸ばした方法／3 ✗人気アイドルは動画を撮って公開しただけで、広告に起用したわけではない／4 ✗価格を下げたという話はない。 |
| 6番 | 3 | 男「毎日一時間ほど歩くことにしてみたんです」「家内も一緒に始めたんですよ」→妻とウォーキングをする。サッカーは「若い頃は、仲間と一緒にサッカーをして」と過去の方法、ランニングは友人に勧められたが「なかなか…」で実行せず、旅行は「今では家族と旅行に行ったときも、旅行先で楽しんでいます」と歩くことの延長として触れられているだけ。 |
