# 【正解・解説】※解き終わってから見てください

## 問題1 課題理解

| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 4 | 妻が「タイマーで途中で切らずに、朝まで適温で使い続けるのが望ましいんですって」、夫が「設定温度を少し高めにして朝までつけておいた方がいいね」と同意している。 |
| 2番 | 1 | 女性が「まずはこちらの申込用紙にご記入ください。その後、受付で面談の日程を調整していただきます」、男性が「用紙に記入しますね」と言っている。 |
| 3番 | 3 | 男性が「まずは棚へのポスター掲示から始めてもらえるかな」、女性が「すぐにポスターを準備して棚に貼りに行きます」と言っている。 |
| 4番 | 1 | 男性が「まずこちらの開設申込書にお名前とご住所をご記入いただけますか…確認書類のご提示は番号がお呼びできた際にお願いいたします」、女性が「書きますね」と言っている。 |
| 5番 | 2 | 男性が「まずはスポット設置に向けて、駅の管理事務所に連絡をとって打診してみてくれ」、女性が「すぐに駅の管理事務所へ電話します」と言っている。 |

## 問題2 ポイント理解

| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 4 | 作業員が「作業台の高さを自分の身長に合わせて調整したのと…特に作業台の高さを正しく合わせたことが一番効果的でした」と述べている。 |
| 2番 | 2 | アナウンサーが「一番の理由は、借りたポートと異なる目的地近くのポートへ自由に返却できる点です」と述べている。 |
| 3番 | 2 | 係員が「スマートフォンによる電子チケットをお持ちのお客様は、専用スキャナーが設置されております西側のBゲートへお進みください」と案内している。 |
| 4番 | 3 | アドバイザーが「一番意識してほしいのは、面接官の質問を最後まで正確に聞き取り、問われていることにズレなく簡潔に答えることです」と助言している。 |
| 5番 | 1 | 気象予報士が「土曜日の午後になると低気圧は東へ抜け、急速に天気が回復して晴れ間が広がる見込みです」と説明している。 |
| 6番 | 1 | 住民が「平日は仕事で帰宅が遅くなるため立ち会いができません」、業者が「今週の土曜日はすでに予約が埋まっておりますが、来週の土曜日でしたら…空いております」と話している。 |

| 番号 | 正解 | ポイント |
|---|---|---|
| 1番 | 3 | 「途中で退席してしまい、申し訳ありませんでした」という謝罪に対し、主催者側として「お忙しい中ご参加いただきありがとうございました」と返すのが適切。 |
| 2番 | 2 | 「新商品のサンプルが届きましたので、お持ちいたしました」という報告に対し、上司として「ありがとう。そこのデスクに置いておいて」と指示するのが適切。 |
| 3番 | 1 | 「15分ほどかかりますが、よろしいでしょうか」という確認に対し、「それくらいなら歩けますので大丈夫です」と答えるのが自然。 |

| 5番 | 1 | 「お忘れ物のないよう、ご確認ください」という注意喚起に対し、「はい、手荷物をもう一度確かめます」と受諾・確認するのが自然。 |
| 6番 | 2 | 「顔が広い（交友関係が広い）」という慣用句に対し、「いろいろな業界に知り合いがいますね」と返すのが適切。 |
