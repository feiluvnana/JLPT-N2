# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 4 | 女「別にチラシも作ってあるんだけど、それを今日、大学の中で配る予定なんだ。その時何人か必要だから、手伝ってくれる」→ちらしを配る。1は「これは一人で大丈夫」と女の学生が一人でやる、2は「その前に学生課で掲示の許可をもらわないといけないから、今から行くんだ」と女の学生の用事、3は「別にチラシも作ってあるんだけど」で作成済み。 |
| 2番 | 1 | 1 ○「今日は一部の商品に割引きシールを付ける作業をやってくれることになってたね」「そのシールを貼る作業が終わってからでいいから」→倉庫より先にやる／2 ✗豆の数を数えるのはシール貼りの後／3 ✗「私もすぐレジを手伝わなきゃいけなくて」→店長がする／4 ✗「レジの横の棚に並べるのは明日の開店前にみんなですればいい」→明日。 |
| 3番 | 2 | 「グループでひとつの国を取り上げ」「今からどの国について調べるか、グループで話し合ってもらいます」「授業の終わりに、私に報告してください」→発表で取り上げる国。テーマ(ゴミ処理)と役割分担は前回決定済み。 |
| 4番 | 2 | 男「まず活動についてまとめた文献を見てみて」→活動をまとめた文献を読む。アート制作やイベント参加は「興味を感じるのがあったら」の後の話、別の人への相談は「その時はまた相談させてください」と今後の話。 |
| 5番 | 3 | 1 ✗自転車は「駐輪禁止区域のため移動しました」で駅前にはない／2 ✗「取りに行くならそれからだよ」→場所を確認した後／3 ○「市役所のホームページに書いてあるから確認して」→まずすること／4 ✗「自転車受け取る時払うよ」で、しかも「警察じゃないと思うけど」。 |

| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 1 ✗「必ずしも長期間担当できなくても良い」→こだわらない条件／2 ✗「美術大学を卒業したかどうかもこだわらないよ」→こだわらない条件／3 ○「学校や絵画教室でも指導経験がない人はちょっとね」「経験の有無は譲れないよ」→最も重視する条件／4 ✗「子供に接することが好きな人だったら、言うことないよね」→あれば尚よい程度。 |
| 2番 | 1 | 1 ○「ソファーはあまり使ってないし、欲しい人にあげてもいいかもしれないね」「あんまり使ってない大きい家具のもらい手を探そうか」→これが結論／2 ✗「冷蔵庫はまだ使うよ!」と女の人が拒否／3 ✗「荷物の積み降ろしって結構大変だよ。やっぱり引っ越し会社に頼んだ方がいい」と退けられる／4 ✗「安い引っ越し会社は見つからないだろうし」。 |
| 3番 | 3 | 男「だから、実際に使う表現が覚えられるんだ」→実用的な日本語が学べるところ。1は「曜日が決まってて。その点はちょっとね」と不満点、2は「先生に日本語の文法とか言葉とかを習うんじゃないんだ」、4は「中にはあまり気が合わない人もいるんだけどね」。 |
| 4番 | 4 | 「自分が納得いくまで何度でも消してやり直せるっていうところが、特にいいと思ってるんだ」→4。費用がかからないのは友達に勧められた理由で、一番の点ではない。 |
| 5番 | 2 | アナウンサー「私もまさかこの箱に花が入っているとは思いませんでした」→箱に入っているのは花。お菓子と宝石は「お菓子が入っていそうな箱や、宝石箱のようなものもあります」と見た目の話にすぎず、コーヒーは「箱にはコーヒーが入っていると思われる方も多いそうです」という客の思い込み。 |
| 6番 | 4 | 「他社製品は2センチ以上の段差があっても…グリーンは1センチ以上に対応できず、これが原因で売れ行きが伸び悩んでいる」→対応できる段差が低い。音・充電・パワーは高評価。 |
