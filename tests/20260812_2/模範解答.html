第 1 問 問題1 漢字読み
正解: 1
今日は朝から三つの会議が連続している。
1れんぞく
2れんそく
3ねんぞく
4ねんそく
詳細解説
【正解の理由・根拠】
「連続れんぞく」の正ただしい読よみは「れんぞく」です。「連れん」も「続ぞく」も音読おんよみで、同おなじミスが続つづいて起おきることを表あらわします。
【各選択肢の解説】
  • 1. [正解] 「れんぞく」は「連続れんぞく」の正ただしい音読おんよみです。会議かいぎが途切とぎれず続つづく意味いみになります。
  • 2. [不正解] 「れんそく」は「続ぞく」を清音せいおんの「そく」と読よんだ間違まちがいです。正ただしくは濁にごった「ぞく」です。
  • 3. [不正解] 「ねんぞく」は「連れん」を「ねん」と読よんだ間違まちがいです。「年ねん」などへの混同こんどうです。
  • 4. [不正解] 「ねんそく」は「連れん」と「続ぞく」の両方りょうほうを誤あやまって読よんだ形かたちです。
【重要語彙・文法ポイント】
連続れんぞく：同おなじことが途切とぎれず続つづくこと（例れい：連続れんぞく出勤しゅっきん）。音読おんよみ：「連れん」「続ぞく」はどちらも音読おんよみで読よむ二字熟語じじゅくご。〜が連続れんぞくする：同おなじ物事ものごとが間あいだを置おかずに並ならぶこと（例れい：連続れんぞくドラマ）。

「ぎょぎょう」を漢字かんじで書かくと「漁業ぎょぎょう」です。「漁ぎょ」は魚さかなを取とること、「業ぎょう」はなりわいを表あらわします。

  • 2. [不正解] 「漁仰」は「業ぎょう」を「仰ぎょう」と書かいた間違まちがいです。
  • 3. [不正解] 「魚業」は「漁ぎょ」を「魚ぎょ」と書かいた間違まちがいです。魚さかなそのものの字じでは「漁業ぎょぎょう」になりません。

漁業ぎょぎょう：魚さかなや海産物かいさんぶつを獲とる産業さんぎょう。漁ぎょと魚ぎょ：同音どうおんだが、「漁ぎょ」は獲とる行為こうい・産業さんぎょう側がわ。業ぎょうと仰ぎょう：同音どうおんの別字べつじ。なりわいは「業ぎょう」。さかんだ（盛さかんだ）：勢いきおいがあって活発かっぱつな様子ようす。

正解: 1

1一休み
2人安み
3一安み
4人休み
詳細解説
【正解の理由・根拠】
「ひとやすみ」を漢字かんじで書かくと「一ひと休やすみ」です。「ひと」は数すうの「一」、「やす（み）」は「休」で書かきます。少すこしの間あいだ、作業さぎょうをやめて休やすむことを表あらわします。
【各選択肢の解説】
  • 1. [正解] 「一休み」が正ただしい表記ひょうきです。「そろそろここで一ひと休やすみしませんか」という誘さそいの文脈ぶんみゃくに合あいます。
  • 2. [不正解] 「人安み」は「ひと」を「人」、「やす」を「安」と書かいた誤あやまりです。読よみは「ひとやすみ」になりますが、語ごとしては存在そんざいしません。
  • 3. [不正解] 「一安み」は「やす」を「安やすい」の「安」と書かいた誤あやまりです。休やすむことを表あらわすのは「休」です。
  • 4. [不正解] 「人休み」は「ひと」を「人」と書かいた誤あやまりです。「一ひと休やすみ」の「ひと」は数すうの「一」で書かきます。
【重要語彙・文法ポイント】
一ひと休やすみ：少すこしの間あいだ休やすむこと（例れい：ここで一ひと休やすみしよう）。一ひと：「ひと」と読よむ訓読くんよみ（一言ひとこと・一ひと休やすみ・一目ひとめ）。休やすむ と 安やすい：読よみはどちらも「やす」だが、休やすむのは「休」、値段ねだんが低ひくいのは「安」。そろそろ：もうすぐ・ちょうどよい時ときになって。
第 8 問 問題2 表記

2治める
3修める
4収める

【正解の理由・根拠】
「成功せいこうをおさめる」の「おさめる」は「収おさめる」と書かきます。「収おさめる」はよい結果けっかを自分じぶんのものにする、という意味いみです。

  • 2. [不正解] 「治おさめる」は国くにや地域ちいきを統治とうちする、争あらそいをしずめる意味いみで、成功せいこうには使つかいません。

  • 4. [正解] 「収おさめる」が正ただしい表記ひょうきです。「成功せいこうを収おさめる」「勝利しょうりを収おさめる」の形かたちで、よい結果けっかを手てに入いれることを表あらわします。

収おさめる：よい結果けっかを手てに入いれる（成功せいこう・勝利しょうりを収おさめる）。同訓異字どうくんいじ「おさめる」：収おさめる／納おさめる／治おさめる／修おさめる。四よっつとも「おさめる」と読よむので、文脈ぶんみゃくで書かき分わける。納おさめる：税ぜいを納おさめる。治おさめる：国くにを治おさめる。修おさめる：学問がくもんを修おさめる。成功せいこうを収おさめる：物事ものごとがうまくいって、よい結果けっかを得えること。

少し熱があるだけなのに、大病のように（　）に言わないでほしい。
1具体的
2大げさ
3率直
4簡潔
詳細解説
【正解の理由・根拠】
少すこし熱ねつがあるだけなのに大病たいびょうのように言いうのは誇張こちょうなので、「大おおげさ」が正ただしいです。
【各選択肢の解説】
  • 1. [不正解] 「具体的ぐたいてき」はくわしく・はっきりした様子ようすで、誇張こちょうの文脈ぶんみゃくには合あいません。
  • 2. [正解] 「大おおげさ」が正ただしく、実際じっさい以上いじょうに大おおきく言いう意味いみです。
  • 3. [不正解] 「率直そっちょく」は隠かくさず正直しょうじきに言いう意味いみで、誇張こちょうとは違ちがいます。
  • 4. [不正解] 「簡潔かんけつ」は短みじかくまとまっている意味いみで、大病たいびょうのように言いうこととは結むすび付つきません。
【重要語彙・文法ポイント】
大おおげさ：実際じっさいより大おおきく言いう・する。具体的ぐたいてき：くわしくてはっきりしている。率直そっちょく：思おもったことをそのまま言いう。

第 26 問 問題6 用法
正解: 3
反発
1向かいのビルの窓が午後の日光を反発して、目を開けていられないほどまぶしかった。
2彼は自分の失敗を反発して、次は慎重に進めた。
3会社の一方的な決定に、若手社員が強く反発した。
4新しい薬に体が反発して、熱が出てしまった。
詳細解説
【正解の理由・根拠】
「反発はんぱつする」は、相手あいての考かんがえや決きめ方かたを受うけ入いれず、強つよく反対はんたいの気持きもちを示しめすことです。一方的いっぽうてきな決定けっていに社員しゃいんが強つよく反対はんたいする3が正ただしい用法ようほうです。
【各選択肢の解説】
  • 1. [不正解] 光ひかりがはね返かえるのは「反射はんしゃする」です。「反発はんぱつ」は人ひとの気持きもちや、磁石じしゃくの同おなじ極きょくどうしが退しりぞけ合あう場合ばあいに使つかい、光ひかりには使つかいません。
  • 2. [不正解] 自分じぶんの失敗しっぱいを振ふり返かえって改あらためるのは「反省はんせいする」です。「反発はんぱつ」は自分じぶんではなく、外そとからの考かんがえや扱あつかいに向むかう気持きもちです。
  • 3. [正解] 「一方的いっぽうてきな決定けっていに反発はんぱつする」は「反発はんぱつ」の典型てんけい的てきな用法ようほうです。納得なっとくできない決きめ方かたに、強つよい反対はんたいの気持きもちを示しめしています。
  • 4. [不正解] 薬くすりに体からだが合あわずに変化へんかが起おきるのは「反応はんのうする」です。「反発はんぱつ」には意志いしをもって反対はんたいするという意味いみがあり、体からだの変化へんかには使つかいません。
【重要語彙・文法ポイント】
反発はんぱつする：相手あいての考かんがえや扱あつかいを受うけ入いれず、強つよく反対はんたいする（例れい：値上ねあげに反発はんぱつする／強つよい反発はんぱつを招まねく）。反射はんしゃする：光ひかりや音おとがはね返かえる。反省はんせいする：自分じぶんの行おこないを振ふり返かえって改あらためる。反応はんのうする：刺激しげきを受うけて変化へんかが起おきる。一方的いっぽうてき：相手あいての意見いけんを聞きかず、片方かたほうだけで決きめること。
第 27 問 問題6 用法
正解: 3
訴える
1弟は試合に勝ったことを、うれしそうに母に訴えた。
2引っ越したので、住所の変更を役所に訴えた。

「訴うったえる」は、苦くるしさや不満ふまん、強つよい主張しゅちょうを相手あいてに切実せつじつに伝つたえることです。痛いたみを伝つたえる3が正ただしい用法ようほうです（「頭痛ずつうを訴うったえる」は病院びょういんでよく使つかわれる形かたち）。
【各選択肢の解説】
