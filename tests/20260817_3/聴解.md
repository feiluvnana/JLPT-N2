# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 先生「ハンさんの勉強の進め方やその工夫などについて紹介してほしいんです」→勉強の工夫。サークル・アルバイト・就職は「そのことについては、他の学生が担当してくれることになってるんです」と別の担当者に割り振られる。 |
| 2番 | 3 | 男「その間に、皆さんには私と一緒にそちらの倉庫から花の苗を運んでいただきます」→まず倉庫から苗を運ぶ。雑草抜きは「午前の方には雑草を抜いて、花壇の整備をしていただきました」と完了済み、目印を付けるのは職員の作業、苗を並べるのは「その後」。 |
| 3番 | 2 | 「グループでひとつの国を取り上げ」「今からどの国について調べるか、グループで話し合ってもらいます」「授業の終わりに、私に報告してください」→発表で取り上げる国。テーマ(ゴミ処理)と役割分担は前回決定済み。 |
| 4番 | 2 | 男「まず活動についてまとめた文献を見てみて」→活動をまとめた文献を読む。アート制作やイベント参加は「興味を感じるのがあったら」の後の話、別の人への相談は「その時はまた相談させてください」と今後の話。 |
| 5番 | 1 | 「日光がよく当たる窓際に移してあげるといいですよ」→まず置く場所を変える。水は「それでいいですよ」、弱った枝は「その必要はないですよ」、植え替えは「元気になったら」。 |

## 問題2
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 4 | 男「ああ、明日は無理ですね」であさってになり、女「あ、待って。留守にしているかもしれないし、やっぱり夜八時以降で」→あさっての夜。午前中は「じゃあ、早いほうがいいんで、それでお願いします」と一度選ばれた後に取り消されている。 |
| 2番 | 3 | 女「もっと宣伝に力を入れたらどうですか？」→男「そうだね、やってみよう」＝ホームページを作る。値下げは「原材料の価格が上がってて厳しい」、早朝開店は「アルバイトを見つけるのが難しい」、チラシの割引券は「売り上げが伸びなかった」。 |
| 3番 | 3 | 1 ✗「自然の豊かなところだった」→感想の一つ／2 ✗「玉ねぎとかトマトとか採ったよ」→事実だが一番ではない／3 ○「クラスメイトの意外な一面を知ることができたんだよね」＋「どんなことよりそっちの方が印象に残ってる」→3が正解。／4 ✗「もちろん農業の面白さも実感できたけど」→譲歩。 |
| 4番 | 1 | 「自分が卒業した高校のサッカー部…そこで、コーチの仕事をする機会を得ました」→高校でサッカーのコーチとして働く。 |
| 5番 | 2 | 「私自身は流れてきた木の枝を拾って、テーブルや椅子なんかを作っています」→家具を作るため。アクセサリーは「作る人が多い」他人の話、貝の研究は友人の話。 |
| 6番 | 4 | 1 ✗「他の子は元気に飛び回って、自分をアピールしていましたが」→他の猫／2 ✗「ずっと寝ているか、あくびをしているか。マイペースな猫だなと思いました」→印象のみ／3 ✗しっぽの形は名前の由来として語られる／4 ○「顔は鼻の周りの毛が黒くて、鼻の穴が大きく見えたのもユニークで可愛かったです」→4が正解。 |
