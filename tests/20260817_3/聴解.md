# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 先生「ハンさんの勉強の進め方やその工夫などについて紹介してほしいんです」→勉強の工夫。サークル・アルバイト・就職は「そのことについては、他の学生が担当してくれることになってるんです」と別の担当者に割り振られる。 |
| 2番 | 3 | 男「興味があるなら、問い合わせてみればいいんじゃない？」→女「そうしてみます」。1 ✗ 訪問はまず問い合わせた後。2 ✗「先輩がいない場合は？」と自分には先輩がいない。4 ✗「それは一応やってるんですけど」で済んでいる。 |
| 3番 | 2 | 「グループでひとつの国を取り上げ」「今からどの国について調べるか、グループで話し合ってもらいます」「授業の終わりに、私に報告してください」→発表で取り上げる国。テーマ(ゴミ処理)と役割分担は前回決定済み。 |
| 4番 | 3 | 「虹のお茶は頭痛でお悩みの方に最適です」→にじのお茶。1は「月のお茶は体を温めてくれます。体が冷えやすい方に向いています」、2は「星のお茶はパソコン等の見すぎで目が疲れている方」、4は「なかなか眠れない方には空のお茶がお勧めです」。 |
| 5番 | 1 | 田中「これから、外に出ますんで、…携帯から、かけ直します」＝自分でかけ直す。2 ✗ 課長は「別の電話に出ております」で、待つとは言っていない。3 ✗ 4 ✗「こちらからお電話させていただきましょうか」の申し出は「あ、いえ」と断っている。 |

## 問題2
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 4 | 男「これは、息子がなにか野菜を作りたいって言って、やってるんだ」→こどもが育てたいと言ったから。農薬については「ぼくはあまり気にしてないんだけど」、節約は「これぐらいじゃ、節約にならないよ」と本人が否定している。 |
| 2番 | 2 | 男「選手一人ひとりの体力の差が出ましたね」「チームグリーンは最後まで運動量が落ちませんでした」→アナウンサー「それが勝敗を分けたんですね」男「ええ、そういうわけです」＝選手の体力が上回っていた。1は「試合前はチームブルーに技術的に優れた選手が多くて楽な試合だろうと思われてた」＝負けた側の話、3・4は「試合が始まったら選手自身の判断が大事なんです。監督の声はほとんど聞こえないんですよ」と否定されている。 |
| 3番 | 3 | 1 ✗「自然の豊かなところだった」→感想の一つ／2 ✗「玉ねぎとかトマトとか採ったよ」→事実だが一番ではない／3 ○「クラスメイトの意外な一面を知ることができたんだよね」＋「どんなことよりそっちの方が印象に残ってる」→3が正解。／4 ✗「もちろん農業の面白さも実感できたけど」→譲歩。 |
| 4番 | 1 | 「自分が卒業した高校のサッカー部…そこで、コーチの仕事をする機会を得ました」→高校でサッカーのコーチとして働く。 |
| 5番 | 2 | 男「いい景色を探して、あちこち歩き回る」／女「私は年中出歩いて、題材を集めているんです」→女「あら、同じですね」。1 ✗ 行き先そのものは合わせていない。3 ✗ 4 ✗「油絵はお金がかかる」「紙と鉛筆があればできます」と、費用も材料も違う点として語られる。 |
| 6番 | 4 | 1 ✗「他の子は元気に飛び回って、自分をアピールしていましたが」→他の猫／2 ✗「ずっと寝ているか、あくびをしているか。マイペースな猫だなと思いました」→印象のみ／3 ✗しっぽの形は名前の由来として語られる／4 ○「顔は鼻の周りの毛が黒くて、鼻の穴が大きく見えたのもユニークで可愛かったです」→4が正解。 |

## 問題3
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 1 | 女「本当の病名だけでなく、あとどれくらい生きられるのかということも知りたいですね」＝自分は知りたい側。2 ✗「ショックで何もできなくなってしまう」のは母。3 ✗「残された日々を無駄にしないように」は自分の話。4 ✗ 家族には「伝えたほうがいいのかどうか、よくわかりません」。 |
| 2番 | 1 | 女「だれに質問しても先に答えてしまうのがねえ」＋「今度は1人でブツブツちょっと小さい声で、やっぱり声出して答えている」＝黙っていられない。2 ✗ 笑うのは注意された直後で、答えないわけではない。3 ✗「宿題もきちんと出す」。4 ✗ となりの学生と話す場面はない。 |
| 3番 | 4 | 1 ✗共に学ぶ必要性の話ではない／2 ✗褒めるタイミングだけでなく注意全体の方法についての話／3 ✗叱ることのデメリットの話ではない／4 ○「注意する時はできているところも伝えて、できないところに目を向けさせるといいでしょう」「注意する際に本人の頑張りを認めることで子供が肯定感を持つことができ」→注意する時に気をつけること。 |
| 4番 | 3 | アナウンサー「小学五年生の小林健太さんの作文が最優秀賞に輝きました」「目に浮かぶように鮮やかに描かれ」→最優秀賞に選ばれた作品について。開催の目的、受賞者本人のコメント、次回の応募方法にはいずれも触れていない。 |
| 5番 | 1 | 「私は否定的に考えずに別の側面を期待しています」「能力の向上を目指す人はこれらを使わない手はないと思います」→利点を積極的に活用すべきだ。 |
