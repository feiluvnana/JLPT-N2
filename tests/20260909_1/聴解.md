# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 女「それで、先生に電話して確かめてもらえないかな」＝同じ初級クラスを担当する木村先生に電話する。空きの確認は「あ、それは大丈夫だった」と済み、山田さんへの連絡は電話で確かめた後、名簿の修正は「山田さんへの連絡が済んだら」とさらに後。 |
| 2番 | 2 | 1 ✗「空いた席のお皿はできるだけ早く下げるようにします」に女が「空いた席のお皿を下げるのは私が…するから」→男の仕事ではない／2 ○「キッチンの手伝いを優先してくれる？ランチセットに出すサラダを小さいお皿に盛って欲しい」→最初に頼まれた仕事／3 ✗お客様の案内は女が担当／4 ✗「キッチンが落ち着いたら、店の外でお待ちのお客様にメニューをお渡ししてくれる？」→後ですること。 |
| 3番 | 3 | 男「私の研究室の前の掲示を見て、宿題を確認してください」＝宿題の確認は掲示で。1 ✗「メールでもいいですか」は休む連絡の話。2 ✗「友達に聞いたりしないで」と否定される。4 ✗ 寮はリンさんへの伝言の話で、掲示の場所ではない。 |
| 4番 | 4 | 女「あと、きのこのピザもお願いしたんですけど」＋「コーヒーのおかわり2つ、お願いします」＝この2つが未提供。1 ✗ 2 ✗「パスタ2種類とシーフードピザは…お持ちしていますよね」、スパゲッティとジュースも「お待たせいたしました」で提供済み。3 ✗ ジュースはもう出ている。 |
| 5番 | 3 | 1 ✗自転車は「駐輪禁止区域のため移動しました」で駅前にはない／2 ✗「取りに行くならそれからだよ」→場所を確認した後／3 ○「市役所のホームページに書いてあるから確認して」→まずすること／4 ✗「自転車受け取る時払うよ」で、しかも「警察じゃないと思うけど」。 |
