# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 先生「ハンさんの勉強の進め方やその工夫などについて紹介してほしいんです」→勉強の工夫。サークル・アルバイト・就職は「そのことについては、他の学生が担当してくれることになってるんです」と別の担当者に割り振られる。 |
| 2番 | 2 | 女「ネギの畑の雑草を抜く作業やってもらえますか？」→まず雑草をとる。収穫は「明日機械でする」、種まきは「これが終わったら」、土を耕すのは「済んでるから」。 |
| 3番 | 2 | 女「ホームページに振り込み先の銀行名と口座番号が書いてあるから振り込みでも払えるよ。確認してみて」→男「もう一度ホームページ見てみる」＝まず振込先を確認。申し込みは支払い後、カードは「2週間くらいはかかる」ので「また今度にしよう」。 |
| 4番 | 2 | 課長「ガラスも悪くはないと思うけど、店の雰囲気から考えると和紙なんかも合うね」→女「そうしてみます」＝素材を変更。位置と高さは「よく考えてあるね」、光の強さと明かりの色は「案の通りで」。 |
| 5番 | 3 | 課長「パンフレットが入った封筒を各机に置いて準備は完了となります」→今日この後の作業。机といすは「準備が整い」、パソコンは「設置は当日行います」、来場者の案内は「当日は」。 |

## 問題2
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 2 | 女「でも私はやっぱり作業が1番楽しみ」＝木を切り倒すなど林業の基本作業の体験。人工呼吸は「知ってて損はないよね」と評価どまり、工作は男が「やってみたいなあ」。 |
| 2番 | 3 | 女「もっと宣伝に力を入れたらどうですか？」→男「そうだね、やってみよう」＝ホームページを作る。値下げは「原材料の価格が上がってて厳しい」、早朝開店は「アルバイトを見つけるのが難しい」、チラシの割引券は「売り上げが伸びなかった」。 |
| 3番 | 1 | 男「ちょうど仕事以外でも人間関係を広げたいと思っていたから他の保護者の皆さんと知り合えないかと思ってね」＝始めた理由。地域と先生は「〜という方も多いですよ」と他人の理由、子供の様子は女の関心。 |
| 4番 | 3 | 女「合わせるもので同じ着物とは思えないってくらい印象が変わるんだよ。私、そこから毎日着たいくらい大好きになっちゃった」＝夢中になったきっかけ。安さは高くない理由、古さは「そういうわけじゃない」、注目は「他の人の目は気にならないんだ」。 |
| 5番 | 1 | 「歩行距離を競うことは、昨年末の社員へのアンケート結果を受けて新たに採用になりました」＝今年度から。他の3つは「三年前から」続く取り組みに含まれる。 |
| 6番 | 3 | 「さらに困難だったのはいくつもの国から協力してもらうこと」＝1番難しかったこと。計測器の開発も「非常に難しかった」がそれ以上、深海の温度測定は目的、データ分析は「時間もかかりますが」どまり。 |
