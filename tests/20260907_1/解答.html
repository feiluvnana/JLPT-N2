包丁の向き

料理を教わり始めたころ、私は味つけばかりを気にしていた。塩をどれだけ入れるか、しょうゆをいつ加えるか。切り方は形をそろえるための作業で、味とは関わりのないものだと思っていた。ところが、同じ材料を同じ調味料で煮ても、日によって仕上がりが違う。その理由が長くわからなかった。

野菜には、水や養分を運ぶ細い管が縦に通っている。この管の並びが繊維である。包丁を繊維の向きに沿って入れれば、管はほとんど切られずに残る。向きを変えて横から入れれば、管は断ち切られ、切り口に小さな穴がいくつも開く。（　48　）、繊維に沿って切れば野菜の中身は閉じたまま残り、繊維を断って切れば、中身が出入りする道が開く。

この違いは、火にかけたときにはっきりする。道が開いていれば、加熱のあいだに水分が外へ出やすく、そのぶん煮汁が中へ入りやすい。同じ大根でも、切る向きを変えただけで（　49　）。煮くずれの起こりやすさも、歯ごたえの残り方も、ここで分かれる。

もっとも、繊維を断てばよいという単純な話ではない。汁をよく含ませたい煮物なら断ち切る向きが合うし、しゃきしゃきした歯ざわりを残したいサラダなら、沿って切ったほうがよい。味がしみないという不満と、水っぽくなるという不満は、どちらも切る向きの選び方から生まれている。切り方で味が変わると聞けば大げさに思えるかもしれないが、水の通り道を開けるか閉じるかを選んでいるのだから、（　50　）。

料理の本に「繊維を断つように切る」と書かれているとき、その一行は、形をそろえるための注意であると同時に、（　51　）。切り口をのぞけば、管が残っているか断たれているかは、目で見て確かめられる。

問題2

問題もんだい2では、まず質問しつもんを聞きいてください。そのあと、問題もんだい用紙ようしを見みてください。読よむ時間じかんがあります。それから話はなしを聞きいて、問題もんだい用紙ようしの1から4の中なかから、最もっともよいものを一ひとつ選えらんでください。

例れい
1. 三着さんちゃくまとめると、仕上しあがりが早はやくなるから
2. 家いえにある二に着ちゃくも、今日中きょうじゅうに直なおしてもらえるから
3. 三着さんちゃく以上いじょうだと、一着いっちゃく分ふんの代金だいきんが安やすくなるから
4. 三着さんちゃくまとめると、家いえまで届とどけてもらえるから

1番ばん

3番ばん

4. 急いそぐときは、そうむが順番じゅんばんを先さきに進すすめてくれる

4番ばん

3. 運はこべない家いえの分ふんを、当番とうばんが取とりに回まわること
4. 集あつめたお金きんを、子こども会かいに渡わたすようにしたこと

5番ばん
1. 冬用ふゆようのタイヤなら鎖くさりは要いらないと分わかり、意外いがいに感かんじている
2. 車くるまに合あう鎖くさりが一組ひとくみもなく、注文ちゅうもんになると、こまっている
3. 鎖くさりをつけるのに三十さんじゅう分ふんもかかることを、めんどうだと思おもっている
4. 去年きょねん、峠とうげの手前てまえで止やめられたことを、今いまも不満ふまんに思おもっている

6番ばん
