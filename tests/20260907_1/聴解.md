# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 女「一番大事なことじゃない。すぐに手配しないと」＝「当日、手伝ってくれる人」の手配。1 ✗「音楽室を借りてあるんだけど」。2 ✗ ポスターは「エミにお願いしたい」と頼んだ。4 ✗「バンドのメンバーが持ってくればいいから」。 |
| 2番 | 1 | 「ご都合のよろしいときに、お貸し出しました携帯電話をご持参の上、当店までおいでください」が依頼。2 ✗「修理ができないことがわかりました」ので修理代は生じない。3 ✗ 相談は「機種変更など」で住所変更ではない。4 ✗ 連絡はこのメッセージで済んでいる。 |
| 3番 | 3 | 課長「今までのものと図で比較するとか、そういう感じの方がいいんじゃないかな」→女「はい、そうします」＝以前の商品と比べた図を入れる。文字の色は「あんまり目立たない」という指摘のみで直す指示はなく、数字は「大きく目立つように書いてある」で十分、変更点のまとめは「他に付け加えるものはないね」と評価済み。 |
| 4番 | 3 | 1 ✗「記念品は袋に入れてくれた?」「まだ届いていないんですよ」「納品は3時だったね」→品物がまだ来ていない／2 ✗「花瓶の移動なんだけど、落とすといけないから記念品の準備の後で私と一緒にやりましょうか」→後回しになった／3 ○「記念品の到着を待ってる間、出席者の名前を書いた紙を椅子に貼ってくれない？」／4 ✗「明日の朝一番に卒業生代表のグエンさんと挨拶のリハーサルをお願いね」→明日。 |
| 5番 | 1 | 「日光がよく当たる窓際に移してあげるといいですよ」→まず置く場所を変える。水は「それでいいですよ」、弱った枝は「その必要はないですよ」、植え替えは「元気になったら」。 |

## 問題2
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 女「やるやるって口ばっかり。私、あなたのそういうところが一番いや」＝口だけで実行しない点。1 ✗ 4 ✗「友達と付き合うなって言ってるわけじゃないよ」と自分で否定。2 ✗ 出来がまずいのではなく「なんにもやってくれなくって」＝手をつけない。 |
| 2番 | 1 | 課長「駐車場が…駐車場がある施設の方が参加者の数が増えると思うんです」→会場に駐車場がない点。予算超過は「多少のオーバーは仕方ない」と問題視していない。 |
| 3番 | 2 | 1 ✗「残業代のアップも私たち社員が声を上げたから実現した」→既に実現済み／2 ○「私は有給とかの休暇の取得申請、もっと簡単に申請できるように改善してほしいんだよね」「私はそうしようと思ってる」／3 ✗在宅勤務を増やしてほしいのは男の人（「そうだ、それを書こう」）／4 ✗パソコンも男の人の希望で、しかも「今年度中には買い換えるって聞いたよ」。 |
| 4番 | 2 | 1 ✗「手ごろな値段で買える店も多いですが」→安さは理由でない／2 ○「頭に浮かんだアイデアを自分の手で家具として完成させていくっていう過程がたまらないんです」／3 ✗「仕事があるので集中して一気に作ることは難しい」→できないこと／4 ✗「うまくできないとストレスになることもある」→逆。 |
| 5番 | 2 | 「私自身は流れてきた木の枝を拾って、テーブルや椅子なんかを作っています」→家具を作るため。アクセサリーは「作る人が多い」他人の話、貝の研究は友人の話。 |
| 6番 | 4 | 「うちの店でまだ扱っていない魚、結構あるよね…うちもいろいろ置いてみようか」→店に置く魚の種類を増やす。価格は「価格が変えられないとしても」、惣菜の種類と宅配は「これ以上…対応できません」と却下。 |

| 1番 | 3 | 開催日の変更は「既に申し込んでる方や選手の都合もありますしね」で不可、試合形式は「今回は初心者も参加できるイベントということで募集してるんですよ」で不可、ポスターは「今回は時間的に厳しいけど次回からは範囲を広げる必要があるね」で次回。「隣の練習用の小さめの運動場も空いています」に「それなら早く押さえたほうがいいね」と決めたので、会場の変更。 |
