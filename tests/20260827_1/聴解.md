# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 2 | 1 ✗「体験参加同意書に署名してお持ちいただけましたか？」「はい、お願いします」→既に済んでいる／2 ○「そちらの棚にエプロンが置いてありますので、ご自分に合うサイズのものをつけてお待ちください」→次にすること／3 ✗「工場の方でガラスの色を先生と相談してお選びいただきます」→エプロンの後／4 ✗「体験後に送料をいただきます」→後ですること。 |
| 2番 | 1 | 「生花の写真なんだけど、位置がいくらか左によっている感じがするんだ。少し真ん中に寄せてくれる？」→写真の位置（1）を直す。タイトル（2）は「見やすくなった」と評価済み、日時（3）は「それは動かさないでいきましょう」で据え置き、場所（4）はこの伝言では修正点として挙げられていない。 |
| 3番 | 2 | 男「少し目立つ色を入れたりするとか、してみてくれます？」女「あ、はい。そうですね」→箱のデザイン（色）を変更する。価格（3）と発売時期（4）は「企画書のままでいい」「今のように…書いていておいてくれれば十分」と変更なし、対象年齢（1）は話題に出ていない。 |
| 4番 | 2 | 男「まず活動についてまとめた文献を見てみて」→活動をまとめた文献を読む。アート制作やイベント参加は「興味を感じるのがあったら」の後の話、別の人への相談は「その時はまた相談させてください」と今後の話。 |
| 5番 | 3 | 1 ✗自転車は「駐輪禁止区域のため移動しました」で駅前にはない／2 ✗「取りに行くならそれからだよ」→場所を確認した後／3 ○「市役所のホームページに書いてあるから確認して」→まずすること／4 ✗「自転車受け取る時払うよ」で、しかも「警察じゃないと思うけど」。 |

## 問題2
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 1 ✗「必ずしも長期間担当できなくても良い」→こだわらない条件／2 ✗「美術大学を卒業したかどうかもこだわらないよ」→こだわらない条件／3 ○「学校や絵画教室でも指導経験がない人はちょっとね」「経験の有無は譲れないよ」→最も重視する条件／4 ✗「子供に接することが好きな人だったら、言うことないよね」→あれば尚よい程度。 |
| 2番 | 3 | 男「スケジュールが流動的でも、対応できる方がいいと思って、今のバイト先は、一週間ごとに予定を提出すればいいんだ」→自分の都合に合わせて働きやすいから。時給は「塾は時給もいいし、楽しかったんだけどね」と塾のほうが良く、友人は「塾で一緒に働いていた友達」、新しい仕事は「覚えることも多くて大変そうだね」と経験のある仕事ではない。 |
| 3番 | 3 | 「私は紐状に細く切ってクッションのカバーや花瓶の下に敷くものを編むのに使っています」→あみものの材料として使う。ゆずる・作り変える・リサイクルショップは他の人の例。 |
| 4番 | 4 | 女「サイズ別に分けて、それをさらに値段の順番で並べてみる?」→男「じゃ、明日の朝、早めに来て取り掛かろう」＝新たにするのは値段の順に並べること。サイズ別は「服の種類サイズ別に分けて見やすく並べたのが、よかったんじゃない」と今日すでにやったこと、色別は「そこまでしなくていいよ」、値札は「変えなくていいんじゃない」と見送られている。 |
| 5番 | 1 | 「今日、木曜日の東京は雲一つない爽やかなお天気となっていますが、明日の午前中までとなりそうです」「東京は明日の午後から曇りとなり」→午前中は晴れるが、午後から曇る。雨は「明後日は朝から雨が降ったり止んだりの天気となる見込みで、夕方には大雨に変わるでしょう」＝明後日の話。 |
| 6番 | 3 | 男「毎日一時間ほど歩くことにしてみたんです」「家内も一緒に始めたんですよ」→妻とウォーキングをする。サッカーは「若い頃は、仲間と一緒にサッカーをして」と過去の方法、ランニングは友人に勧められたが「なかなか…」で実行せず、旅行は「今では家族と旅行に行ったときも、旅行先で楽しんでいます」と歩くことの延長として触れられているだけ。 |
