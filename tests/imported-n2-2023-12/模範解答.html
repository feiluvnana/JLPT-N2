第 1 問 問題1 漢字読み
正解: 2
昨日から腕が痛くて困っている。
1こし
2うで
3かた
4ひざ
詳細解説
【正解の理由・根拠】
「腕うで」は、肩かたから手てまでの部分ぶぶんです。「腕」の訓読くんよみは「うで」で、音読おんよみは「ワン」（例：腕力わんりょく）です。正解は2です。
【各選択肢の解説】
  • 1. [不正解] こし：「腰こし」の読よみです。体からだの真まん中なかあたり、背中せなかの下したの部分を指さします。
  • 2. [正解] うで：「腕」の訓読みです。「腕が痛いたい」「腕を組くむ」のように使つかいます。
  • 3. [不正解] かた：「肩かた」の読みです。首くびと腕うでのつなぎ目めの部分です。
  • 4. [不正解] ひざ：「膝ひざ」の読みです。足あしの曲まがる関節かんせつの部分です。
【重要語彙・文法ポイント】
腕うで：肩から手までの部分。例：腕を上あげる。「腕」の音読みは「ワン」。例：腕力わんりょく、敏腕びんわん。体からだの部分ぶぶんの漢字かんじはまとめて覚おぼえる：腰こし・肩かた・膝ひざ・胸むね・額ひたい。慣用句かんようく「腕がいい」＝技術ぎじゅつが高たかい。「腕を磨みがく」＝技術を高たかめる。
第 2 問 問題1 漢字読み
正解: 3
青木さんは善良な人です。
1せんりょう
2ぜんりゅう
3ぜんりょう
4せんりゅう
詳細解説
【正解の理由・根拠】
「善良ぜんりょう」は、性格せいかくがよく、正直しょうじきなことです。「善」の音読みは「ゼン」で濁にごり、「良」の音読みは「リョウ」で長音ちょうおんです。正解は3です。
【各選択肢の解説】
  • 1. [不正解] せんりょう：「善」を清音せいおんの「セン」と読よんでいます。「善」は「ゼン」です。
  • 2. [不正解] ぜんりゅう：「良」を「リュウ」と読んでいます。「良」は「リョウ」です。
  • 3. [正解] ぜんりょう：善＝ゼン、良＝リョウ。「善良な人ひと」「善良な市民しみん」の形かたちで使います。
  • 4. [不正解] せんりゅう：「善」「良」ともに読み方が違ちがいます。
【重要語彙・文法ポイント】
善良ぜんりょう：性格がよく正直なこと。例：善良な市民しみん。「善」を使う語：善意ぜんい、改善かいぜん、最善さいぜん。いずれも「ゼン」。「良」を使う語：良好りょうこう、優良ゆうりょう、良心りょうしん。いずれも「リョウ」。「ゼン／セン」「リョウ／リュウ」は濁だく音おんと拗音ようおんの聞きき分わけが問とわれやすい。
第 3 問 問題1 漢字読み
正解: 1
丸山さんは意外に幼いところがある。
1おさない
2するどい
3かしこい
4しつこい
詳細解説
【正解の理由・根拠】
「幼おさない」は、年としが小ちいさい、子こどもっぽいという意味いみです。「意外いがいに幼いところがある」で、大人おとななのに子どもっぽい面めんがあるという文ぶんになります。正解は1です。
【各選択肢の解説】
  • 1. [正解] おさない：「幼い」の読よみです。「幼い子こども」「考かんがえが幼い」のように使つかいます。
  • 2. [不正解] するどい：「鋭するどい」の読みです。先さきがとがっている、感覚かんかくが優すぐれているという意味で、漢字かんじが違ちがいます。
  • 3. [不正解] かしこい：「賢かしこい」の読みです。頭あたまがよいという意味で、漢字が違います。
  • 4. [不正解] しつこい：ひらがなで書かく語ごで、「幼い」とは関係かんけいがありません。
【重要語彙・文法ポイント】
幼おさない：年が小さい。子どもっぽい。例：幼い妹いもうと、考えが幼い。「幼」の音読おんよみは「ヨウ」。例：幼児ようじ、幼稚ようち、幼少ようしょう。意外いがいに：思おもっていたことと違って。例：意外に簡単かんたんだった。読みの似にた形容詞けいようしをまとめて覚おぼえる：幼い・鋭するどい・賢かしこい・しつこい。
第 4 問 問題1 漢字読み
正解: 4
古いデータを削除した。
1そくよ
2さくよ
3そくじょ
4さくじょ
詳細解説
【正解の理由・根拠】
「削除さくじょ」は、書かいてあるものやデータを消けして取とり除のぞくことです。「削」の音読みは「サク」、「除」の音読みは「ジョ」です。正解は4です。
【各選択肢の解説】
  • 1. [不正解] そくよ：「削」を「ソク」、「除」を「ヨ」と読んでいます。どちらも誤あやまりです。
  • 2. [不正解] さくよ：「削」は正ただしく「サク」ですが、「除」は「ジョ」です。
  • 3. [不正解] そくじょ：「除」は正しく「ジョ」ですが、「削」は「サク」です。
  • 4. [正解] さくじょ：削＝サク、除＝ジョ。「データを削除する」「名前なまえを削除する」の形で使います。
【重要語彙・文法ポイント】
削除さくじょする：消して取り除く。例：ファイルを削除する。「削」の訓読みは「けず（る）」。例：予算よさんを削けずる。「除」を使う語：除外じょがい、掃除そうじ、解除かいじょ。反対はんたいの意味の語：追加ついかする、加くわえる。
第 5 問 問題1 漢字読み
正解: 2
私たちは働く機会の平等を求めています。
1へいど
2びょうどう
3びょうど
4へいどう
詳細解説
【正解の理由・根拠】
「平等びょうどう」は、差さがなく同おなじに扱あつかわれることです。「平」を「ビョウ」、「等」を「ドウ」と読む、特別とくべつな組くみ合あわせの読みです。正解は2です。
【各選択肢の解説】
  • 1. [不正解] へいど：「平」を「ヘイ」と読み、「等」も短みじかく読んでいます。二ふたつとも誤りです。
  • 2. [正解] びょうどう：平＝ビョウ、等＝ドウ。「男女だんじょ平等」「平等な機会きかい」の形で使います。
  • 3. [不正解] びょうど：「等」の長音ちょうおんが足たりません。「ドウ」と伸のばします。
  • 4. [不正解] へいどう：「平」の読みが「ヘイ」になっています。この語ごでは「ビョウ」です。
【重要語彙・文法ポイント】
平等びょうどう：差がなく同じであること。例：法ほうの下もとの平等。「平」は語ごによって読みが変かわる：平和へいわ・平気へいきは「ヘイ」、平等は「ビョウ」、平たいらは訓読み。「等」を使う語：等級とうきゅう、同等どうとう、高等こうとう。「平等」だけ「ドウ」になる点てんに注意ちゅうい。関連語かんれんご：公平こうへい（＝かたよりがない）、対等たいとう（＝立場たちばが同じ）。
第 6 問 問題2 表記
正解: 3
お金のかんりは、きちんとしてください。
1管利
2官理
3管理
4官利
詳細解説
【正解の理由・根拠】
「かんり」は「管理かんり」と書かきます。「管」は「カン」（くだ・パイプの意味）、「理」は「リ」です。「お金かねの管理」は、お金をきちんと扱あつかい、把握はあくしておくことです。正解は3です。
【各選択肢の解説】
  • 1. [不正解] 管利：「管」は正しいですが、「利リ」は利益りえき・便利べんりの「利」で、意味が合あいません。
  • 2. [不正解] 官理：「官カン」は役所やくしょ・役人やくにんの意味（例：官庁かんちょう）で、ここでは使いません。
  • 3. [正解] 管理：管＝カン、理＝リ。「時間じかんの管理」「健康けんこう管理」などの形で使います。
  • 4. [不正解] 官利：二字にじとも誤りです。
【重要語彙・文法ポイント】
管理かんりする：うまく扱い、きちんとした状態じょうたいを保たもつ。例：在庫ざいこを管理する。「管」を使う語：管理、血管けっかん、水道管すいどうかん。訓読みは「くだ」。「理」を使う語：理由りゆう、整理せいり、処理しょり。同おなじ「カン」の音おとの漢字を区別くべつする：管・官・館・関・感。

第 8 問 問題2 表記
正解: 2
社会はたえず変化している。
1完えず
2絶えず
3停えず
4滞えず
詳細解説
【正解の理由・根拠】
「たえず」は「絶たえず」と書きます。「絶える」は続つづいていたものが切きれることで、打うち消けしの「ず」がついて「切れることなく＝いつも」という意味になります。正解は2です。
【各選択肢の解説】
  • 1. [不正解] 完えず：「完」は「かん」と読み、「たえる」という読み方はありません。
  • 2. [正解] 絶えず：「絶える」＝切れる、終おわる。「絶えず変化へんかしている」＝ずっと変化し続けている。
  • 3. [不正解] 停えず：「停」は「テイ」（停止ていし・停電ていでん）で、「たえる」とは読みません。
  • 4. [不正解] 滞えず：「滞」は「タイ」「とどこお（る）」で、「たえる」とは読みません。
【重要語彙・文法ポイント】
絶たえず：切れることなく続いて。例：絶えず努力どりょくする。「絶」を使う語：絶対ぜったい、断絶だんぜつ、絶望ぜつぼう。他動詞たどうしは「絶たつ」。同どうじ「たえる」と読む字じ：耐たえる（＝我慢がまんする）。意味が違うので使い分わける。似た意味の副詞ふくし：常つねに、たえまなく、しきりに。

選挙で誰にとうひょうするかまだ決めていない。

2当票
3投標
4当標
詳細解説
【正解の理由・根拠】
「とうひょう」は「投票とうひょう」と書きます。選挙せんきょで、自分じぶんが選えらぶ人ひとの名なを書いた票ひょうを出だすことです。「投」は「トウ」、「票」は「ヒョウ」です。正解は1です。
【各選択肢の解説】
  • 1. [正解] 投票：投＝トウ、票＝ヒョウ。「選挙で投票する」「投票率とうひょうりつ」の形で使います。
  • 2. [不正解] 当票：「当トウ」は当あたる意味で、票ひょうを投なげる動作どうさを表あらわしません。
  • 3. [不正解] 投標：「標ヒョウ」は目印めじるしの意味（例：目標もくひょう）で、選挙の「票」ではありません。
  • 4. [不正解] 当標：二字とも誤りです。
【重要語彙・文法ポイント】
投票とうひょうする：票を出す。例：期日前きじつまえ投票。「投」を使う語：投手とうしゅ、投資とうし。訓読みは「な（げる）」。「票」を使う語：票ひょう、伝票でんぴょう、投票。「標」（目標・標識ひょうしき）と区別する。選挙せんきょの関連語：候補者こうほしゃ、選挙区せんきょく、当選とうせん。

正解: 4
中島さんは何かをかかえて部屋に入ってきた。
1押えて
2捕えて
3握えて
4抱えて
詳細解説
【正解の理由・根拠】
「かかえて」は「抱かかえて」と書きます。「抱える」は、両手りょうてや腕うでで物ものを胸むねのあたりに持もつことです。正解は4です。
【各選択肢の解説】
  • 1. [不正解] 押えて：「押おさえる」で、上うえから力ちからを加くわえて動うごかないようにすることです。読みも意味も違います。
  • 2. [不正解] 捕えて：「捕とらえる」で、逃にげるものをつかまえることです。
  • 3. [不正解] 握えて：「握にぎる」は手てを閉とじて強つよく持つことで、「かかえる」とは読みません。
  • 4. [正解] 抱えて：「抱える」＝腕で持つ。「荷物にもつを抱えて歩あるく」「問題もんだいを抱える」の形で使います。
【重要語彙・文法ポイント】
抱かかえる：腕で持つ。例：本ほんを抱えて運はこぶ。比喩ひゆの使い方：問題を抱える、借金しゃっきんを抱える＝解決かいけつしていないものを持っている。「抱」の音読みは「ホウ」。例：抱負ほうふ。訓読みは「だ（く）」「いだ（く）」もある。手てで持つ動作の動詞どうし：持もつ・握にぎる・抱かかえる・支ささえる。使い分けを覚える。

彼は兄に対抗（　）を持っているようだ。
1心
2欲
3願
4熱
詳細解説
【正解の理由・根拠】
「対抗心たいこうしん」で、相手あいてに負まけたくないという気持きもちを表あらわします。「〜心」は「その気持ち」を作つくる接尾語せつびごです。正解は1です。
【各選択肢の解説】
  • 1. [正解] 心：「対抗心」＝負けたくない気持ち。「〜心」は気持ちを表す接尾語です。
  • 2. [不正解] 欲：「〜欲」は欲ほしがる気持ち（例：意欲いよく、食欲しょくよく）で、「対抗欲」という語はありません。
  • 3. [不正解] 願：「願がん」は願ねがいの意味（例：志願しがん）で、この形かたちでは使いません。
  • 4. [不正解] 熱：「〜熱」は熱中ねっちゅうする気持ち（例：熱意ねつい、教育熱きょういくねつ）ですが、「対抗熱」とは言いいません。
【重要語彙・文法ポイント】
対抗たいこうする：相手に負けないように張はり合あう。例：他社たしゃに対抗する。〜心しん：その気持ち。例：好奇心こうきしん、自信じしん、警戒心けいかいしん、向上心こうじょうしん。〜欲よく：欲しがる気持ち。例：意欲、食欲、欲求よっきゅう。接尾語せつびごは結むすびつく語が決きまっている。語彙ごいごとに組くみ合あわせで覚える。
第 12 問 問題3 語形成
正解: 4
引っ越しのための（　）手続きをしなければならない。
1総
2複
3多
4諸
詳細解説
【正解の理由・根拠】
「諸手続しょてつづき」で、「いろいろな手続き」という意味になります。「諸〜」は「いくつもの、さまざまな」を表す接頭語せっとうごです。正解は4です。
【各選択肢の解説】
  • 1. [不正解] 総：「総そう〜」は全体ぜんたいをまとめる意味（例：総人口そうじんこう、総額そうがく）で、「総手続き」とは言いません。
  • 2. [不正解] 複：「複ふく〜」は重かさなる意味（例：複数ふくすう、複雑ふくざつ）で、この形では使いません。
  • 3. [不正解] 多：「多た〜」は数すうが多いこと（例：多方面たほうめん、多機能たきのう）ですが、「多手続き」とは言いません。
  • 4. [正解] 諸：「諸〜」＝いろいろな。「諸手続き」「諸問題しょもんだい」「諸事情しょじじょう」の形で使います。
【重要語彙・文法ポイント】
諸しょ〜：さまざまな。例：諸問題、諸費用しょひよう、諸国しょこく。かたい書かき言葉ことば。手続てつづき：必要ひつような事務じむの流ながれ。例：入学にゅうがくの手続きをする。総そう〜：全体の。例：総選挙そうせんきょ、総収入そうしゅうにゅう。接頭語せっとうごは語ごの意味を限定げんていする。諸・総・各かく・全ぜんの違ちがいを整理せいりしておく。
第 13 問 問題3 語形成
正解: 2
買い物をしている二人（　）にインタビューをしました。
1出かけ
2連れ
3会い
4集まり
詳細解説
【正解の理由・根拠】
「二人連ふたりづれ」で、いっしょに行動こうどうしている二人という意味になります。「〜連れ」は、いっしょにいる人ひとを表す接尾語です。正解は2です。
【各選択肢の解説】
  • 1. [不正解] 出かけ：「出でかける」は外そとに行いく動作どうさで、人数にんずうを表す言い方にはなりません。
  • 2. [正解] 連れ：「二人連れ」＝二人でいっしょにいる人たち。「親子おやこ連れ」「子こども連れ」も同じ作つくりです。
  • 3. [不正解] 会い：「出会であい」などの形はありますが、「二人会い」とは言いません。
  • 4. [不正解] 集まり：「集あつまり」は人が集まる会かいのことで、「二人集まり」とは言いません。

【各選択肢の解説】
  • 1. [不正解] タイプ1：学内がくないの寮りょうですが「部屋は4人部屋よにんべや」で、1人になれません。
  • 2. [不正解] タイプ2：ホームステイで「大学から遠とおい場合ばあいもあります」と説明せつめいされ、「大学に近くて」という条件に合いません。
  • 3. [不正解] タイプ3：1人用ひとりようのアパートで条件は満みたしますが、女の学生は「キッチンとかは共同っていうのにする」と、はっきり共同のほうを選えらんでいます。
  • 4. [正解] タイプ4：「キッチンなどは共同で利用りようしますが、部屋は1人部屋です」で、大学の近くという条件も満たします。
【重要表現・リスニングポイント】
プライバシー：他人たにんに入はいられたくない私的してきな部分ぶぶん。例：プライバシーを守まもる。共同きょうどうで利用りようする：みんなで使つかう。例：共同のキッチン。〜さえ／〜ればいい：条件じょうけんを一ひとつに絞しぼる言い方。例：一人になれればいい。二ふたつの質問しつもんがある問題もんだいでは、二人ふたりの条件じょうけんをメモで分わけて書かき取とる。同おなじ四よつの選択肢せんたくしを二度にど使つかう。
