# 【正解・解説】※解き終わってから見てください

## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 2 | 男「今度の場所は駐車場がないんですよね。忘れてました」＝今日知らせるのはこれだけ。1 ✗「月曜日にメールしました」で済んでいる。3 ✗「開始時間はそのままだから、大丈夫ですよ」。4 ✗ 終わる時間も「それはもう月曜日のメールで」。 |
| 2番 | 1 | 先生「ちゃんと資料を読んでから行くのよ」→男「資料って、インターネットで申し込めますか」＝まず資料の請求。2 ✗「先輩に会って話を聞いたら」で済んでいる。3 ✗ 資料を読んでから行く順。4 ✗「調べているうちに…はっきりしてくる」＝資料の後。 |
| 3番 | 2 | 「グループでひとつの国を取り上げ」「今からどの国について調べるか、グループで話し合ってもらいます」「授業の終わりに、私に報告してください」→発表で取り上げる国。テーマ(ゴミ処理)と役割分担は前回決定済み。 |
| 4番 | 2 | 課長「ガラスも悪くはないと思うけど、店の雰囲気から考えると和紙なんかも合うね」→女「そうしてみます」＝素材を変更。位置と高さは「よく考えてあるね」、光の強さと明かりの色は「案の通りで」。 |
| 5番 | 3 | 1 ✗自転車は「駐輪禁止区域のため移動しました」で駅前にはない／2 ✗「取りに行くならそれからだよ」→場所を確認した後／3 ○「市役所のホームページに書いてあるから確認して」→まずすること／4 ✗「自転車受け取る時払うよ」で、しかも「警察じゃないと思うけど」。 |

| 2番 | 4 | 男「ここの駅って、深いよねー」→「地震が来たら…。ああ、考えるだけでぞっとするよ」＝深さがこわい。1 ✗「安全対策も立ててるだろうし」は女の言葉。3 ✗ 時間ではなく深さを問題にしている。2 ✗ バスは「時間が読めないからダメ」で、速さの比較はしていない。 |
| 3番 | 4 | 巣箱を設置してフクロウを呼び戻し「ネズミの数を減らすことに成功しました」→ネズミの被害を減らすための工夫。 |
| 4番 | 4 | 「自分を表現するという意味で、満足感もあります」「着る服や音楽もとてもきれいで…楽しみのひとつ」→フィギュアの魅力が主題。1 ✗ 始めた理由は述べていない。2 ✗「速さだけに頼るというのに限界を感じる」→限界の話。3 ✗「人によって評価が変わります」→魅力の一部。 |
| 5番 | 4 | 1 ✗「その手間を減らすことができる」と利点を述べる／2 ✗米の味の話はない／3 ✗ロボットを作る難しさは述べていない／4 ○「そこで活躍しているのが田んぼの水に浮かぶ小型のロボットです」「この新しい技術を取り入れることによって」→米作りでのロボットの活用。4が正解。 |
